# Mawlid al-Nabi al-Sharif — Interactive Web Experience

A festive, single-file web experience for Mawlid al-Nabi al-Sharif, built with vanilla HTML, CSS, and JavaScript — no frameworks or build step required.

## Features

- **Animated hero** — glowing crescent moon, swinging lanterns, and a walking camel silhouette with a real leg-swing gait
- **3D fireworks** — particle bursts with depth (translateZ/perspective), triggered automatically and on click
- **Scroll-revealed landmarks** — Masjid an-Nabawi, Masjid al-Haram, and Masjid Quba illustrated with hand-drawn SVGs that draw themselves in as you scroll
- **Lantern-catching mini-game** — catch gold/green lanterns in a basket, avoid red ones (they destroy nearby lanterns), 3 lives, difficulty ramps up over time (faster falls, shorter spawn intervals, more red lanterns)
- Fully responsive, RTL-first (Arabic), respects `prefers-reduced-motion`

## Files

- `mawlid.html` — the main animated landing page
- `lantern-game.html` — the standalone catching game

## Usage

Just open either `.html` file in a browser — no build tools, no dependencies beyond Google Fonts (Aref Ruqaa, Reem Kufi, Tajawal).
